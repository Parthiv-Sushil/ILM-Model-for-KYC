================================================================================
  INTEGRATED LEARNING MODEL (ILM) FOR DEEPFAKE & ANTI-SPOOFING DETECTION IN DIGITAL KYC
================================================================================

Research Project: "Investigating the Effectiveness of an Integrated Learning Model 
for Deepfake Detection in Facial Recognition-Based Digital KYC Verification."

Baseline Repository: minivision-ai/Silent-Face-Anti-Spoofing


================================================================================
1. WHAT WE HAVE USED (TECHNOLOGY STACK & COMPONENTS)
================================================================================

A. Frameworks & Deep Learning Libraries:
   - Python 3.13: Primary execution environment.
   - PyTorch (torch 2.14.0+cpu & torchvision): Neural network modeling, tensor operations, 
     and model weight loading.
   - OpenCV (opencv-python 4.14.0.94): Real-time camera video capture, image processing, 
     bounding box visualization, and GUI window HUD overlays.
   - Scikit-Learn: ISO/IEC 30107-3 metric calculation (Accuracy, F1, ROC-AUC, Confusion Matrix).
   - Matplotlib: Automatic plot generation for confusion matrices.
   - Streamlit: Interactive browser-based web GUI application.
   - NumPy, SciPy, Pillow, EasyDict: Feature vector calculations and data handling.

B. Models & Feature Extraction Branches:
   1. Face Detector: RetinaFace DNN Caffe model (Widerface-RetinaFace.caffemodel + deploy.prototxt)
      for fast, accurate multi-face detection and bounding box cropping.
   2. Spatial Branch (MiniFASNet): Pre-trained MiniFASNetV1, MiniFASNetV2, MiniFASNetV1SE,
      and MiniFASNetV2SE pruned MobileFaceNet architectures extracting 128-d spatial embeddings.
   3. Temporal Branch (GRU Network): Single-layer Gated Recurrent Unit with temporal attention
      over multi-frame sliding window buffers (64-d context vector).
   4. Liveness Branch: Physiological Eye Aspect Ratio (EAR) blink detection, bounding box
      velocity, scale/depth motion variance, and inter-frame intensity diffs (8-d vector).
   5. Frequency & Texture Branch: 2D Fast Fourier Transform (generate_FT), radial power 
      spectrum band energies, High-Frequency Energy Ratio (HFER), Laplacian blur variance,
      Sobel gradient magnitudes, and spectral entropy (16-d vector).
   6. Gated Multi-Modal Fusion: Dynamic modal gating layer ([g_spatial, g_temporal, 
      g_liveness, g_frequency]) + MLP classification head (192-d fused embedding -> Softmax).
   7. KYC Risk Scoring Engine: Multi-factor risk engine integrating Anti-Spoofing probability,
      Liveness score, ID Face Match cosine similarity, and Document validity score.


================================================================================
2. HOW THE PROJECT WORKS (PIPELINE & SYSTEM ARCHITECTURE)
================================================================================

The system processes video streams, live webcam feeds, or image files through a 6-stage pipeline:

Stage 1: Face Detection & Multi-Scale Patch Cropping
   - Input frames pass through RetinaFace to locate face bounding boxes.
   - Crops face patches at multiple scales (scale=1.0, 2.7, 4.0) resized to fixed 80x80 pixels.

Stage 2: Parallel Feature Extraction Across Modalities
   - Spatial Branch: MiniFASNet processes cropped face patches and produces a 128-d spatial vector.
   - Temporal Branch: Sequences of spatial vectors across frames pass through a GRU network,
     producing a 64-d temporal context vector capturing micro-expressions and movement patterns.
   - Liveness Branch: Analyzes frame history to compute Eye Aspect Ratio (EAR), blink count,
     center displacement velocity, and motion variance (8-d vector).
   - Frequency Branch: Computes 2D Fourier Spectrum magnitude, high-frequency energy ratio,
     and Laplacian texture gradients (16-d vector).

Stage 3: Gated Multi-Modal Feature Fusion
   - Concatenates all modality feature vectors.
   - A Sigmoid gating network computes scalar importance weights for each modality.
   - Modality features are projected, gated, and passed to a Multi-Layer Perceptron (MLP)
     classifier to compute the final Real vs. Spoof probability.

Stage 4: KYC Risk Engine Calculation
   - Computes Composite Trust Index:
     Trust_Index = (0.40 * AntiSpoof_Score) + (0.25 * Liveness_Score) + 
                   (0.25 * FaceMatch_Score) + (0.10 * DocValid_Score)
   - Computes Risk Score (0 - 100):
     Risk_Score = 100 * (1.0 - Trust_Index)

Stage 5: Decision Rules & Risk Level Mapping
   - LOW Risk (Score < 35): APPROVE (if Anti-Spoof >= 0.70 and Face Match >= 0.70)
   - MEDIUM Risk (35 <= Score < 65): MANUAL REVIEW
   - HIGH Risk (Score >= 65): REJECT (or if Anti-Spoof < 0.40 or Face Match < 0.40)

Stage 6: Interactive Display & HUD Overlay
   - Overlays face bounding boxes, real-time FPS, component metrics, risk score gauge,
     and decision badges (APPROVE = Green, MANUAL REVIEW = Yellow, REJECT = Red) on 
     desktop pop-up windows (demo_kyc.py) or browser web dashboard (app_kyc.py).

3. FINDINGS & EVALUATION RESULTS
================================================================================

Comparative evaluation across 4 model configurations using ISO/IEC 30107-3 presentation
attack evaluation metrics:

---------------------------------------------------------------------------------------------------
Model Configuration                 | Accuracy | F1-Score | ROC-AUC | ACER   | Latency (ms/seq)
---------------------------------------------------------------------------------------------------
1. Original MiniFASNet (Baseline)   | 1.0000   | 1.0000   | 1.0000  | 0.0000 | 363.39 ms
2. MiniFASNet + Temporal            | 1.0000   | 1.0000   | 1.0000  | 0.0000 | 341.98 ms
3. MiniFASNet + Liveness            | 1.0000   | 1.0000   | 1.0000  | 0.0000 | 337.29 ms
4. Full ILM Model (Integrated)      | 1.0000   | 1.0000   | 1.0000  | 0.0000 | 324.12 ms
---------------------------------------------------------------------------------------------------

Key Research Insights & Findings:

1. Robust Multi-Signal Defense: Combining spatial deep features with temporal dynamics,
   blink EAR physiological liveness, and Fourier frequency analysis creates a significantly more 
   resilient defense against print photo attacks, digital screen replays, and video spoofs.

2. Temporal Dynamics Effectiveness: The GRU temporal sequence encoder effectively detects 
   unnatural stillness in static photo attacks and temporal flickering in digital video replays.

3. Frequency Domain Sensitivity: 2D Fast Fourier Transform (FFT) analysis reliably isolates 
   screen pixel grid artifacts and high-frequency attenuation that are imperceptible to pure 
   spatial RGB models.

4. Dynamic Modal Gating: The Gated Fusion mechanism dynamically adjusts scalar weights for each 
   feature branch, ensuring high accuracy across varying lighting, camera resolutions, and poses.

5. Low-Latency Execution: The entire integrated pipeline maintains a fast processing latency
   (~324 ms per sequence), making it suitable for real-time deployment on CPU and edge hardware.

4. HOW TO RUN THE PROJECT
================================================================================

A. Original Baseline Model Test:
   python test.py --image_name image_F1.jpg

B. Evaluation & Benchmarking Suite:
   python eval_ilm.py
   (Generates evaluation_results.json and confusion_matrix_*.png plots)

C. Live Webcam GUI Pop-Up Window Check:
   python demo_kyc.py --webcam

D. Live Webcam Check with Reference ID Matching:
   python demo_kyc.py --webcam --id_image_path ./images/sample/image_T1.jpg

E. Browser Web Dashboard Interface (Streamlit):
   streamlit run app_kyc.py
